# SmartFeedback — Анализатор тональности отзывов Wildberries

Сервис автоматической классификации тональности покупательских отзывов с маркетплейса Wildberries.

---

## 1. Паспорт проекта

- **Название проекта:** `SmartFeedback: сервис анализа тональности отзывов Wildberries`
- **Автор:** `<Карасева Анастасия Аркадьевна>`
- **Группа:** `<БСБО-52-24>`
- **Контакт:** `<@ravrey>`

- **Краткое описание (2-4 предложения):**

  Проект посвящён построению сервиса автоматического анализа тональности покупательских отзывов с маркетплейса Wildberries.
  Сервис классифицирует произвольный текст отзыва на три категории: `positive`, `neutral`, `negative` — и возвращает сводную статистику по пакету отзывов.
  Используется открытый датасет [`ai-forever/ru-reviews-classification`](https://huggingface.co/datasets/ai-forever/ru-reviews-classification) (75 000 русскоязычных отзывов с Wildberries, лицензия CC BY 4.0).
  Целевой пользователь — продавец или менеджер по качеству, которому нужно быстро понять настроение покупателей без ручного разбора сотен текстов.

- **Уровень сложности:** `[BASIC]`

- **Домен (по examples-topics.md):** Раздел 5.4 — «Классификация тональности/тематик отзывов»

- **Метрика успеха:**
  - ML-метрика: **F1-macro ≥ 0.80** на тестовой выборке
  - Бизнес-метрика: сервис обрабатывает батч из 100 отзывов менее чем за 5 секунд на CPU

## 5. Данные

- **Источник:** открытый датасет [`ai-forever/ru-reviews-classification`](https://huggingface.co/datasets/ai-forever/ru-reviews-classification) от AI Forever (Сбер), опубликован на Hugging Face.

- **Лицензия:** CC BY 4.0 — допускает учебное использование при указании источника.

## 8. Ограничения и дальнейшая работа

В текущей версии:

- данные ограничены доменом «одежда и аксессуары» Wildberries — модель может хуже работать на отзывах из других категорий товаров;
- сервис не хранит историю запросов;
- нет авторизации и rate-limiting.

В дальнейшем можно добавить:

- дообучение на отзывах других категорий (электроника, косметика);
- выделение ключевых тем в негативных отзывах (aspect-based sentiment);
- простой веб-интерфейс для ввода отзывов без использования API напрямую;
- хранение истории предсказаний в базе данных.
