# Данные проекта

Папка содержит **демонстрационную выборку** для быстрой проверки работоспособности сервиса.  
Полный датасет загружается автоматически при обучении через Hugging Face `datasets`.

---

## Файлы в папке

| Файл | Размер | Описание |
|---|---|---|
| `sample.csv` | ~131 КБ | 1 000 случайных строк из train-части датасета для smoke-тестов и демонстрации |

### `sample.csv` — структура

| Колонка | Тип | Описание |
|---|---|---|
| `id` | int | Уникальный идентификатор отзыва |
| `text` | str | Текст отзыва на русском языке |
| `label_text` | str | Класс тональности: `positive`, `neutral`, `negative` |
| `label` | int | Числовой код класса: `0` — positive, `1` — neutral, `2` — negative |

Пример строки:
```
id,text,label_text,label
12345,"Отличный товар, очень доволен качеством!",positive,0
```

## Источник данных

**Датасет:** [`ai-forever/ru-reviews-classification`](https://huggingface.co/datasets/ai-forever/ru-reviews-classification)  
**Правообладатель:** AI Forever (Сбер)  
**Лицензия:** CC BY 4.0 — разрешено использование в учебных и исследовательских целях  
**Характеристики полного датасета:**

| Split | Строк |
|---|---|
| train | 60 000 |
| test | 15 000 |
| **Итого** | **75 000** |

Данные обезличены: отзывы содержат только текст и метку класса, без имён покупателей, адресов или иных персональных сведений.

## Загрузка полного датасета

Полный датасет **не хранится в репозитории** — он скачивается автоматически при запуске обучения:

```bash
# Запуск обучения — датасет скачается в HF_CACHE_DIR (по умолчанию ~/.cache/huggingface)
python -m src.train

# Или указать кастомную папку кеша через конфиг:
# configs/config.yaml → hf_cache_dir: ./data/hf_cache
```

Для ручной загрузки:

```python
from datasets import load_dataset

ds = load_dataset("ai-forever/ru-reviews-classification")
print(ds)
# DatasetDict({
#     train: Dataset({features: ['id', 'text', 'label_text', 'label'], num_rows: 60000})
#     test:  Dataset({features: ['id', 'text', 'label_text', 'label'], num_rows: 15000})
# })
```

## Требования к хранению

Согласно политике репозитория, в эту папку **нельзя** добавлять:
- реальные персональные данные третьих лиц
- конфиденциальные или служебные данные
- большие «сырые» выгрузки (файлы > 10 МБ)

`sample.csv` соответствует всем требованиям: это обезличенная выборка открытого датасета под свободной лицензией.
