## 2. Protocol

Опишите ваш "честный" unsupervised-протокол.

- Для каждого датасета использовался **единый и явный препроцессинг**:
  - `SimpleImputer(strategy="median")` (на случай пропусков),
  - `StandardScaler()` для масштабирования числовых признаков.
- Препроцессинг применялся **одинаково ко всем моделям** внутри одного датасета.
- Поиск гиперпараметров:
  - **KMeans**: перебор `k` в диапазоне `2…20`, фиксировались `random_state` и `n_init`;
  - **DBSCAN**: подбор `eps` (на основе расстояний до k-го соседа и квантилей) и `min_samples` из `[5, 10]`.
- Критерий выбора лучшего решения:
  - основной — максимальный `silhouette_score`;
  - для DBSCAN метрики считались **только на non-noise точках**, дополнительно учитывалась доля шума (noise penalty).
- Используемые метрики качества:
  - `silhouette_score` (выше — лучше),
  - `davies_bouldin_score` (ниже — лучше),
  - `calinski_harabasz_score` (выше — лучше).
- Визуализация:
  - PCA(2D) scatter для лучшего решения на каждом датасете;
  - графики подбора параметров (silhouette vs k / silhouette vs eps).

## 3. Models

Для каждого датасета сравнивались следующие алгоритмы:

- **KMeans**
  - подбирался параметр `k`,
  - фиксировались `random_state` и `n_init`.

## 4. Results

### 4.1 Dataset A

- Лучший метод и параметры: **KMeans**, `k = 2`
- Критерий выбора: `max silhouette (kmeans)`
- Метрики:
  - silhouette = **0.5216**
  - Davies–Bouldin = **0.6853**
  - Calinski–Harabasz = **11786.95**
- DBSCAN (для сравнения):
  - `eps = 0.479675`, `min_samples = 10`
  - silhouette (non-noise) = 0.3954
  - доля шума = **8%**
- Вывод:
  После масштабирования KMeans дал наилучшее разделение кластеров по всем внутренним метрикам. DBSCAN выделил значимую долю шума и показал худший silhouette, поэтому был отвергнут.

### 4.2 Dataset B

- Лучший метод и параметры: **DBSCAN**, `eps = 0.71713`, `min_samples = 10`
- Критерий выбора: `max silhouette (non-noise) with noise penalty`
- Метрики (non-noise):
  - silhouette = **0.3726**
  - Davies–Bouldin = **0.5457**
  - Calinski–Harabasz = **148.80**
- Доля шума: **3.26%**
- Сравнение с KMeans:
  - KMeans (`k=2`): silhouette = 0.3069, DB = 1.3235
- Вывод:
  Наличие нелинейной структуры и выбросов делает DBSCAN более подходящим для этого датасета. Он дал лучшее качество разбиения при небольшой доле шума.

### 4.3 Dataset C

- Лучший метод и параметры: **KMeans**, `k = 3`
- Критерий выбора: `max silhouette (kmeans)`
- Метрики:
  - silhouette = **0.3155**
  - Davies–Bouldin = **1.1577**

- DBSCAN (для сравнения):

- Вывод:

## 5. Analysis

### 5.1 Сравнение алгоритмов

- **KMeans** хорошо работает после масштабирования на данных с компактными кластерами, но плохо справляется с выбросами и нелинейной геометрией.
- **DBSCAN** эффективен при наличии выбросов и плотностной структуры, но чувствителен к выбору `eps` и может терять качество при неоднородной плотности.
- Масштабирование признаков оказалось критическим фактором качества для всех distance-based методов.

### 5.2 Устойчивость

- Проверка устойчивости проведена на **Dataset A**.
- Метод: 5 запусков KMeans с разными `random_state`, оценка сходства разбиений через ARI.
- Результат:
  Средние значения ARI оказались высокими, что указывает на стабильность кластеризации при фиксированном `k=2`.
- Вывод:
  Разбиение Dataset A методом KMeans является устойчивым к инициализации.

### 5.3 Интерпретация кластеров

- Основной инструмент интерпретации — PCA(2D) визуализации.
- Выводы:
  - для Dataset A и C кластеры в PCA-пространстве визуально хорошо разделимы,
  - для Dataset B DBSCAN дополнительно выделяет выбросы как шум, что согласуется со структурой данных.

## 6. Conclusion

- Масштабирование — ключевой этап при кластеризации числовых данных.
- KMeans эффективен для компактных кластеров, но чувствителен к выбросам.
- DBSCAN позволяет учитывать шум и плотностную структуру, но требует аккуратного подбора параметров.
- Внутренние метрики (silhouette, Davies–Bouldin, Calinski–Harabasz) позволяют сравнивать решения без истинных меток, но должны интерпретироваться совместно.
- Проверка устойчивости и PCA-визуализация дополняют количественные метрики и повышают надёжность выводов.
