## 1. Dataset

- Какой датасет выбран: `S06-hw-dataset-01.csv`
- Размер: 1000 строк, 26 столбцов
- Целевая переменная: `target` — бинарная классификация  
  - класс 0: ~67%  
  - класс 1: ~33%
- Признаки: в основном числовые (`num01`–`num24`), присутствуют признаки с дискретными значениями, похожие на категориальные, что делает датасет удобным для деревьев решений и ансамблей.

## 2. Protocol

- Разбиение: train/test = 75% / 25%, `random_state=42`, `stratify=y`
- Подбор: GridSearchCV **только на train**, 5-fold Stratified CV  
  Оптимизировалась метрика ROC-AUC
- Метрики:
  - accuracy — базовая интерпретируемая метрика
  - F1 — учитывает баланс precision/recall
  - ROC-AUC — основная метрика для бинарной классификации, устойчива к умеренному дисбалансу классов и использует вероятности модели

## 3. Models

В эксперименте сравнивались следующие модели:

- **DummyClassifier** (`most_frequent`) — baseline
- **LogisticRegression** (через `Pipeline(StandardScaler + LogisticRegression)`) — линейный baseline из S05
- **DecisionTreeClassifier**  
  Подбирались параметры контроля сложности:
  - `max_depth`
  - `min_samples_leaf`
  - `ccp_alpha`
- **RandomForestClassifier**  
  Подбирались параметры:
  - `max_depth`
  - `min_samples_leaf`
  - `max_features`
- **GradientBoostingClassifier**  
  Подбирались параметры:
  - `n_estimators`
  - `learning_rate`
  - `max_depth`
  - `subsample`

Для всех моделей с подбором гиперпараметров использовался честный протокол: CV только на train, test — один раз для финальной оценки.

## 4. Results

Финальные метрики на test:

| Model                         | Accuracy | F1     | ROC-AUC |
|------------------------------|----------|--------|---------|
| RandomForest (best_cv)       | 0.935    | 0.895  | 0.970   |
| GradientBoosting (best_cv)   | 0.929    | 0.886  | 0.968   |
| DecisionTree (best_cv)       | 0.863    | 0.785  | 0.911   |
| LogisticRegression (Scaled)  | 0.830    | 0.715  | 0.879   |
| Dummy (most_frequent)        | 0.677    | 0.000  | 0.500   |

**Победитель:** `RandomForestClassifier`  
Выбран по максимальному ROC-AUC на test (0.970), что указывает на лучшую способность модели различать классы по вероятностям.

## 5. Analysis

- **Устойчивость:**  
  При изменении `random_state` (проверено на нескольких запусках для RandomForest и GradientBoosting) относительный порядок моделей сохраняется, а значения ROC-AUC колеблются незначительно (в пределах ~0.01), что говорит о стабильности ансамблей.

- **Ошибки:**  
  Confusion matrix для RandomForest показывает хорошее разделение классов: низкое число false negatives и false positives по сравнению с базовыми моделями.

- **Интерпретация:**  
  По permutation importance (top-15) наибольший вклад в предсказание вносят признаки:
  `num19`, `num18`, `num07`, `num04`, `num20`, `num01`.  
  Это согласуется с тем, что ансамбли деревьев эффективно используют нелинейные взаимодействия числовых признаков и способны выделять наиболее информативные из них.

## 6. Conclusion

- Деревья решений легко переобучаются без контроля сложности.
- Bagging и RandomForest существенно уменьшают variance по сравнению с одиночным деревом.
- Boosting (GradientBoosting) показывает качество, близкое к RandomForest, но обучается дольше.
- Ансамбли значительно превосходят линейные модели и baseline’ы на этом датасете.
- Честный ML-протокол (CV на train, test один раз) критически важен для корректной оценки качества.
- ROC-AUC является предпочтительной метрикой для бинарной классификации с дисбалансом.
